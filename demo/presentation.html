dejavu — the agent that remembers

Forgetting is a bug · Remembering is the strategy
A memory-driven agent whose onchain (Base) decisions are changed by what it remembers across fresh sessions.
the pitch
🟦 Session A learns a painful lesson → writes it to persistent memory.
🟦 Session B cold-starts with zero context, recalls it, and de-risks.
🟦 Delete the memory → it forgets → loses again. That's the gate.
🟦 Runs on NEURAL_MESH (six lanes) × Sibyl Memory (the substrate) × Base + Virtuals.
