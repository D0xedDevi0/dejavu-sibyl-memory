# 00  /  thesis
Every "AI memory" product on the market is a retrieval system — embeddings, vector search, recall quality. They ask one question: how well does the agent find what it already stored? We asked the questions nobody is asking: what deserves to be written? what does it not know? when should it refuse? and who gets to delete it?

This is the answer as one continuous arc of 16 layers — not sixteen demos, one spine. The memory isn't a filing cabinet. It's a live, typed, tamper-evident data layer that owns itself, earns from itself, and writes itself.

# doctrine  /  why this beats memory-as-database
The field built memory retrieval. We built memory with a conscience — it knows what it doesn't know (L10), vetoes what hurts (L11), trades what it learns (L12, live on x402), agrees on truth (L13), schedules its own education (L14), distills experience into capability (L15), and defends its own right to exist (L16).
