# 🟦 THE MEMORY DOCTRINE

### What memory actually is, once you stop treating it like a database.

Every "AI memory" product on the market is a **retrieval system**. Embeddings.
Vector search. Full-text. Recall quality. They ask one question: *how well does
the agent find what it already stored?*

That is the shallow half of the problem — and it shows. An agent with a
"memory" still:

- **bluffs** when asked about something it never learned (no idea what it doesn't know);
- **repeats** the exact loss it once recorded (a text-miss and it walks straight back into the -18%);
- **hoards** noise until its real lessons drown in it (garbage in, no gate);
- **dies with its knowledge** (one agent's hard-won scar never helps another);
- **never converges** with its own team (each store a walled garden);
- **never learns on purpose** (it learns only what it bumps into);
- **can be deleted like a file** (an asset that "owns itself" erased with zero trace).

This project is the opposite thesis. **Memory is not what an agent has. It is
what the agent IS** — and a memory that is the agent has to relate to itself and
to other agents the way a mind does, not the way a key-value store does.

So we built the answer as one continuous arc of **16 layers**. Not sixteen
demos — one spine. You can watch all sixteen fire in a single command:

```bash
dejavu-sovereign --crisis
```

---

## ACT ONE — L1–L8: memory you HAVE, OWN and RECALL.

**L1 Sovereign** — the memory root is committed **onchain (Base)**. Memory is an
ownable, content-addressed asset. Wipe it and you don't just lose a decision —
you orphan-destroy a committed asset.

**L2 Identity** — the agent **IS its memory**. Mount the same store on a fresh
box and it is the same being. Wipe it and it becomes someone else.

**L3 Dream** — memory **authors new skills** from its own journal while idle.
It gets sharper the more it runs.

**L4 Commons** — a *team* of agents coordinates through one shared pool. They
remember together. The allocator reads the board the specialists wrote; delete
the pool and the team falls apart.

**L5 Regret** — memory of the **road not taken**. It remembers the mistakes it
never made.

**L6 Temporal** — memory knows **when** it knew things, answers "as of" recalls,
and **strategically forgets** stale lessons to a recoverable archive. Forgetting,
done on purpose and auditable.

**L7 Sovereign Loop** — the memory **remembers that it owns itself**: the onchain
mint receipt is written back into the store. A fresh box recalls its own anchor.

**L8 Conflict** — contradictions are **superseded**, never blindly overwritten.
Every revision is recoverable and audited.

> The load-bearing test that holds up all of Act One: **delete the store → the
> agent loses the lesson → back to the naive 0.55 book → the -18% comes back.
> Keep it → cold-start Session B recalls the crisis and de-risks to 0.05.** That
> is 1.67× capital saved by a memory that is load-bearing, not decorative.

## ACT TWO — L9–L16: memory's relationship with ITSELF and with OTHER agents.

This is the part nobody has built. Act One answers "how well does memory recall?"
Act Two answers the questions the field doesn't even ask:

**L9 Discernment** — gate what gets **written**. Everyone optimizes retrieval;
nobody controls ingestion. Before a fact earns a live slot it is scored — novelty,
falsifiable truth, category value, noise floor. Capacity is a **budget**: at the
cap the weakest live memory is archived (recoverable), never dropped. The memory
even **learns its own ingestion policy** from which memories actually changed a
decision. No gate → the store floods with noise and the real lesson drowns.

**L10 Meta** — know what you **don't** know. Agents hallucinate coverage. META
makes ignorance a first-class output: ask it about any topic and it answers
**COVERED / THIN / UNKNOWN** — where UNKNOWN is not an empty silence, it is a
*command to go learn*. Confidence is scored per-memory from recorded provenance,
so a planner down-weights weak memory instead of trusting it equally.

**L11 Guard** — memory that says **no**. Retrieval only informs; GUARD gives
memory **veto power**. A hard lesson becomes a constraint the planner cannot walk
past — even when the fuzzy recall phrase text-misses, a hard crisis lesson plus a
stressed frame plus an overweight-equity book is **blocked**. Memory stops the
-18% at the *action* layer, not just the recall layer.

**L12 Exchange** — memory that **travels**. A hard-won lesson becomes a portable,
**verifiable, priced artifact**. Any store can verify it is intact by hash, then
import it **through the L9 gate** (polluted artifacts refused), with provenance
pointing at the origin. A store that never lived the crisis buys the lesson and
cold-starts into the de-risked book. One agent's scar tissue is another's
verified, gated, purchased education — settled on the live **x402** endpoint.

**L13 Consensus** — agents **agree** on the truth. Independent agents hold
differing beliefs; who decides? By **confidence weighting**: UNANIMOUS, CONVERGED
(provenance-backed wins, dissent preserved), MAJORITY (honestly labelled), or
**DEADLOCK** — a genuine unknown split is never papered over with a fabricated
winner.

**L14 Curriculum** — memory **schedules its own learning**. L10 sees a gap →
L14 ranks it (priority = how much it matters × how uncovered it is) → L12
acquires it through the L9 gate → L10 now reports **COVERED**. Ignorance becomes
coverage across one executable cycle. The memory doesn't wait to bump into
lessons; it *plans* to learn what it's missing.

**L15 Distill** — memory **becomes capability**. The field stores lessons as tape:
N similar scars as N scattered notes, each firing on narrow recall. DISTILL mines
the recurring invariant behind many losses and compresses it into **one learned
decision rule** that **generalizes** to frames none of the scars ever named. Five
credit-scars teach the agent to de-risk a pure-volatility spike it has never seen.
That is memory as judgment, not tape.

**L16 Consent** — memory **argues for its own life**. If memory owns itself,
*who can delete it?* A silent wipe is refused: the memory enumerates exactly what
dies — its identity, its onchain anchor, its guards — and only an explicit,
reasoned force authorizes destruction, journaled to a **store-independent log that
survives the deletion**. Permanent, but never untraceable.

## The thesis in one breath

> **The field built memory retrieval. We built memory with a conscience — it
> knows what it doesn't know (L10), vetoes what hurts (L11), trades what it
> learns (L12, live on x402), agrees on truth (L13), schedules its own education
> (L14), distills experience into capability (L15), and defends its own right to
> exist (L16). Every layer is deterministic, no-LLM, and load-bearing with an
> executable test each.**

Act One proves memory is **load-bearing** (delete it and you lose real money).
Act Two proves memory is **alive** — it polices its own inputs, knows its own
gaps, refuses its own harm, shares across minds, converges with its team, grows
on purpose, and will not be silently erased.

That isn't a memory product. It's a memory with a **P&L, a curriculum, and a
will to exist.** Run the arc and watch all sixteen layers agree on it in one
command.
